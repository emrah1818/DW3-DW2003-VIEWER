# DW3 / DW2003 Viewer 0.1.0 (erste Testversion)

Betrachter für die Kampfmodelle von **Digimon World 3 (USA)**: echte Modelle, Originaltexturen und
Originalanimationen aus deinem eigenen Abbild. Keine Spieldaten enthalten.

**Download:** `DW3_DW2003_Viewer_Windows_x64.zip` unten bei den Assets – entpacken, `DW3_DW2003_Viewer.exe`
starten. Nichts muss installiert werden. Anleitung: `ANLEITUNG.md` im Paket.

## Enthalten
- Abbild öffnen (.cue/.bin/.iso), Version erkennen, 249 Modelldateien mit Spielnamen, Suche, Filter.
- 3D-Ansicht mit PS1-Pixeln, Drahtgitter, Gitter, Skelett, Hintergrund, Bild speichern.
- Animationen abspielen, Einzelbild, Tempo, Schleife, Vergleich zweier Motions; vom Spiel ausgeblendete Teile
  werden auch hier ausgeblendet.
- HD-Texturen (beliebige Größe, ohne Farbreduzierung), Export GLB/OBJ/PNG/JSON.

## Geprüft
- 21 automatische Tests (15 ohne Spieldaten auf GitHub, 6 mit eigenem USA-Abbild), Oberflächentest mit dem
  USA-Abbild (21 Prüfungen).
- Windows-Paket: automatischer Starttest auf dem GitHub-Windows-Rechner (Fenster, WebGL 2 über Direct3D 11,
  lokaler Server) und Start des Konverters.
- **Noch nicht** auf einem echten Windows-PC mit Spieldaten getestet – bitte ausprobieren.

## Noch offen
Augenanimation, PS1-Mischmodi, Effektmodelle, Debug-Ansicht der Körperteile. PAL (Digimon World 2003) ist
